## Reconstruction

The original MENUUI36 cache expired. HOMEONLY2 reconstructs it exactly by:

1. restore the still-live B19 build container only for the build directory/toolchain;
2. `git reset --hard HEAD` to remove all cached NativeBoot working-tree source changes;
3. download the archived cumulative MENUUI36 source diff from run 35435737554;
4. apply that diff to recreate the exact MENUUI36 source state;
5. hard-gate that NativeBoot/CompatBoot markers are absent;
6. apply only the Home path patches;
7. build and save a new clean HOMEONLY2 cache.
