# HOMEONLY1 — Menu3 → Real Home Screen

Date: 2026-09-29

## Goal

Stabilize the real Nokia 5800 / S60v5 Home Screen as a small standalone development path.
Do not carry NativeBoot, PhoneUI startup, CompatBoot Menu Probe, or DirectHome while Home is being debugged.
After Home is stable, integrate the validated Home path back into the app's **Emulator** entry.

## Clean baseline

- Authority: device-validated MENUUI14 INPUTDISPATCH1 FIX2.
- This baseline predates NativeBoot.
- Keep the existing Menu3 / normal HLE runtime and working iOS input path.

## HOMEONLY1 runtime route

```
normal EKA2L1 library
  -> Menu3 UID 0x101F4CD2
  -> iOS existing launcher
  -> real Home Screen UID 0x102750F0
```

Menu3 remains alive under Home.

## Included Home-only changes

1. `apply_m3home1_homebridge.py`
   - Adds **Vào màn hình chính** only while Menu3 is running.
   - Calls the existing iOS launcher for UID 0x102750F0.
   - Does not use PhoneUI or ailaunch.

2. `apply_homeonly1_cenreptx1.py`
   - Generic Central Repository transaction Start/Commit/Cancel support.
   - Generic Set-on-missing compatibility.
   - No Home/FEP repository UID hardcode.

3. `apply_homeonly1_cenrepdeleterange1.py`
   - Implements EDeleteRange / opcode 0x21.
   - Supports staged transaction tombstones and commit.
   - No Home repository/key hardcode.

4. `apply_homeonly1_cenrepgetstringdiag1.py`
   - Diagnostic-only GetString probe for the Home `USER 11` boundary.
   - Records repo/key/string length/destination max/write length.
   - Does not change GetString semantics.

## Explicitly excluded

- Native Boot
- B20–B98 NativeBoot patch chain
- PhoneUI startup/replay/bypass
- CompatBoot Menu Probe
- DirectHome / six-service ailaunch route
- TfxServer fake/shim
- firmware changes

Old branches remain intact for later comparison and reintegration.

## Device evidence inherited from M3HOME1/M3HOME2

- Home UID 0x102750F0 launches as a real Symbian process/window group.
- Home gets WindowServer focus.
- Touch events hit the Home window.
- M3HOME2 resolved unsupported CenRep opcode 0x21 / EDeleteRange.
- The next observed failure is Home self-panic:
  - category: USER
  - reason: 11
- Therefore the current HOMEONLY diagnostic target is the final CenRep GetString activity immediately before USER 11.

## Build strategy

First HOMEONLY1 migration build:
- reconstruct the clean MENUUI14 FIX2 baseline once;
- apply only the four Home-only patches;
- compile and run binary gates;
- reject the build if `[NBOOT2]`, `CompatBoot`, or PhoneUI probe markers remain;
- save a new HOMEONLY1 cache.

Subsequent Home builds:
- restore HOMEONLY1 cache;
- apply only the next Home delta;
- incremental compile;
- package IPA.
