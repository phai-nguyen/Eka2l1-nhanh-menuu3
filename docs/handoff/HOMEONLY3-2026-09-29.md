# DEPRECATED — HOMEONLY3 host-lifecycle experiment

Date: 2026-09-29

## Correction from device tester

The previous interpretation of the HOMEONLY2 video was wrong.

What actually happened:
1. Menu3 launched the real Home Screen.
2. Home disappeared and EKA2L1 returned to its app library.
3. The later transition to the iOS Home Screen was a manual user swipe, not an EKA2L1 crash.
4. The user then reopened EKA2L1 and opened Menu3 to verify that MANIC skin was still present.
5. That second session appended new log data and contaminated the original Home-failure boundary.

Therefore the earlier conclusion that:
`Home exit -> onAppExited -> exitGame -> emulator reboot -> iOS app crash`
was not supported by the video.

## Status

HOMEONLY3 was built from a false host-crash premise.

Do not use HOMEONLY3 as the main diagnostic baseline and do not infer a frontend lifecycle bug from that test.

HOMEONLY2 remains the authoritative baseline:
- MENUUI36 WINFOCUS1
- NOJAVA
- MANIC3
- real Home launch from Menu3
- Home UID 0x102750F0
- CenRep transaction/DeleteRange support
- GetString diagnostics
- NativeBoot absent
- CompatBoot absent
- J2ME absent

The HOMEONLY3 branch/artifact may be retained only as an isolated experiment for future comparison.
