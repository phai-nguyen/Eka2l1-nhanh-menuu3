2. At 16:48:51.938 the real Home thread panics:

Therefore:
- real Home touch is NOT yet working;
- the visible Home image after 16:48:51.938 is stale;
- the Options popup shown in the screenshots belongs to Menu3;
- HOMEONLY4 EventReady probing is not the next bottleneck because the tested touch happened after Home was already dead.

## USER 11 boundary

The final Home Central Repository operation immediately before panic is:

- repository 0x10275104
- key 0xA0001000
- entry_len = 52
- destination max = 2048
- write_len = 52
- status = 0

So the observed CenRep write itself does not exceed its destination descriptor.

The Symbian USER/11 panic class is associated with 16-bit descriptor overflow / assignment of data longer than a target descriptor.

Current working hypothesis:
Home receives the CenRep string successfully, then a later guest-side descriptor operation copies/assigns data into a smaller descriptor and triggers USER/11.

Do NOT change CenRep string lengths/content until the guest callsite is identified.
